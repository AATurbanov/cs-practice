git diff показывает разницу между незакоммиченным кодом и индексом
git show показывает детальную информацию о коммите
git log показывает список коммитов с информацией о них (хеш, автор, дата, описание)
log -S находит коммиты, в которых добавлена или удалена сторка
blame показывает файл построчно, выводя для каждой строки хеш коммита, автора, дату

git restore файл возвращается к состоянию, сохраненному в индексе или к последнему коммиту (если индекс пуст)
git restore --source=HEAD~2 lab03/calc.py возвращает файл к состоянию 2 коммита назад

git revert не стирает коммит, а создаёт новый, отменяющий изменения
git reser --hard полностью стирает коммит, откатывая историю назад
revert безопаснее, потому что всегда можно вернуться к прежнему коммиту

Ветка - подвижный указатель на коммит, тег - статичная метка конкретного коммита
