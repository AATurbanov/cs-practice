git diff показывает разницу между незакоммиченным кодом и индексом
git show показывает детальную информацию о коммите
git log показывает список коммитов с информацией о них (хеш, автор, дата, описание)
log -S находит коммиты, в которых добавлена или удалена сторка
blame показывает файл построчно, выводя для каждой строки хеш коммита, автора, дату
