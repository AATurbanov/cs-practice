Использованные команды

git status
состояние рабочей папки и индекса

git diff
сравнивает рабочую папку с индексом, показывает изменения, которые еще не добавили в индекс

git diff --staged
сравнивает индекс с последним коммитом


Ветки

Ветка - подвижный указатель на коммит

Что происходит с веткой при новом коммите?
Указатель текущей ветки сдвигается на новый коммит, другие ветки остаются на своих местах

Что делает слияние?
Объединяет изменения одной ветки в другую. Создается merge-коммит, в котором соединяются истории обеих веток.
